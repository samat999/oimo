# OIMO Sales — CRM отдела продаж

Адаптивное веб-приложение по ТЗ `docs/TZ_OIMO_technology_sales_app.pdf`.
Телефон и компьютер, кабинеты продавца и владельца.

## Запуск

```bash
cd oimo
npm install
npm run dev
```

Открыть: http://127.0.0.1:5174

## Что есть в первой версии

- Вход с разграничением прав
- Кабинет продавца: план, KPI, зарплата, рейтинг, график, добавление продажи с фото
- Проверка серийного номера на дубликат
- Панель владельца: обзор, подтверждение/отклонение, сотрудники, планы недели/месяца/года, таблица KPI, журнал, Excel
- Часовой пояс Asia/Bishkek
- Нижнее меню на телефоне, сетка карточек на десктопе

Складской учёт и прибыль по закупочной цене — следующий этап, как в ТЗ.
