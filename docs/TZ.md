# Техническое задание — приложение отдела продаж OIMO technology

Исходный PDF: `docs/TZ_OIMO_technology_sales_app.pdf`.

Цель: учёт продаж, планы, автоматический KPI и зарплата, рейтинг. Продавец фиксирует каждую единицу товара с фото, серийным номером и ценой. Владелец проверяет отчёты в одной панели.

Первая версия: адаптивное веб-приложение (телефон и компьютер).

Решения для v1, которые в ТЗ просили согласовать:

- Зарплата: недельный KPI, ставка достигнутого диапазона на все подтверждённые продажи недели плюс бонус диапазона.
- План: штуки и опционально сумма в сомах, независимо неделя / месяц / год.
- Подтверждение: только владелец.
- Рейтинг: по числу подтверждённых продаж. Чужие зарплаты продавцам скрыты.
- Склад: не в первой версии.
