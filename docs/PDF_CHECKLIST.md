# Сверка с ТЗ (TZ_OIMO_technology_sales_app.pdf, 6 страниц)

Обозначения: ✅ сделано и проверено тестом или вручную · ◐ частично · ✗ не сделано · ⚖ требует решения владельца.

## 1. Роли и права доступа
| Требование | Статус | Как реализовано / что осталось |
|---|---|---|
| Продавец входит под своим логином и паролем | ✅ | Email + пароль (от 12 символов), сеансы на сервере |
| Продавец видит только свои продажи, планы, прогресс, бонусы, рейтинг, начисления | ✅ | Фильтрация на сервере; тест «staff cannot…», «ratings expose only names and counts» |
| Продавец создаёт отчёты и видит их статус | ✅ | Форма продажи, статусы в списке |
| Продавец не меняет подтверждённые продажи, правила KPI, настройки других | ✅ | Проверка роли на сервере до проверки параметров (403) |
| В рейтинге видны разрешённые владельцем показатели коллег, без зарплат | ◐ | Видны только имена и количество ноутбуков; **владелец не может настроить набор показателей** |
| Владелец: доступ ко всем сотрудникам, отчётам, продажам | ✅ | |
| Планы на неделю/месяц/год | ✅ | Независимые цели |
| Настройка KPI, ставок, бонусов, правил | ✅ | Версии правил с датой начала |
| Проверка фото, серийных номеров, цен; подтверждение/отклонение | ✅ | Отклонение и возврат только с причиной |
| Выгрузка отчётов и ведомостей, история изменений | ✅ | XLSX продаж и ведомости, журнал действий |

## 3. Форма отчёта о продаже
| Требование | Статус | |

| Фото: камера телефона или загрузка | ✅ | JPG/PNG/WebP до 6 МБ, тип по сигнатуре; браузер телефона предлагает камеру или галерею |

| Комментарий — необязательно | ✅ | |
| Автоматически сотрудник, дата и время | ✅ | Сотрудник назначается сервером |
| Статусы «На проверке / Подтверждён / Отклонён», причина отклонения | ✅ | |
| Неподтверждённая продажа не влияет на KPI | ✅ | Тест |
| Дубликаты: проверка, предупреждение, блокировка | ✅ | Уникальный индекс БД для активных продаж |
| …«без разрешения администратора» | ◐ | Разрешения на дубль нет: владелец отклоняет или возвращает существующую продажу |
| При корректировке/отмене — автор, время, причина, прежние значения | ✅ | Журнал с предыдущим статусом и причиной |

## 11. Решения, которые нужно согласовать
Платформа — веб (сделано). Зарплата — недельный KPI, месячные/годовые бонусы ⚖. План — штуки и/или сомы (оба поддержаны). Подтверждение — владелец (сделано; менеджера нет). Рейтинг — по количеству ноутбуков (выручка в рейтинге ⚖). Склад — сверки с остатками нет ⚖.
